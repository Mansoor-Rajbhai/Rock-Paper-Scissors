# ✊ 📄 ✂️ Rock Paper Scissors

A clean, minimal Rock Paper Scissors game — built to practice core JavaScript logic, DOM manipulation, and localStorage persistence.

**[▶ Play it live](#)** _(swap this with your GitHub Pages link once it's deployed)_

---

## 🎮 About

Nothing fancy, just the classic game — you vs. the computer, best of infinity. Pick your weapon, and the score keeps itself (even after you close the tab, thanks to `localStorage`).

This project was built mostly by hand while learning JavaScript fundamentals — DOM selection, event handling via `onclick`, object literals, and conditional logic — with a bit of AI help for polish and a few UI touches borrowed for design inspiration.

## ✨ Features

- 🪨 Rock, 📄 Paper, ✂️ Scissors — the timeless trio
- 🧠 Random computer opponent (no cheating, promise)
- 💾 Score persists across page reloads via `localStorage`
- 🔁 One-click score reset
- 🎨 Clean, minimal UI with a soft slate & blue color palette
- 🖐️ Icon-based moves using Font Awesome hand icons

## 🛠️ Built With

- **HTML** — structure
- **CSS** — styling (Google Sans font, rounded cards, hover animations)
- **Vanilla JavaScript** — game logic, DOM updates, localStorage
- **[Font Awesome](https://fontawesome.com/)** — icons

No frameworks, no build tools — just the fundamentals.

## 📚 What I Learned

This project was a hands-on way to practice:

- Working with objects and object property access (`icons[move]`)
- Reading and writing to `localStorage`
- Updating the DOM dynamically with `innerHTML`
- Variable scope — and why globally-declared elements are accessible everywhere in a script, but locally-declared ones aren't
- Basic conditional game logic (win/lose/tie detection)
